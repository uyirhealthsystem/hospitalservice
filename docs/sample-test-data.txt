================================================================================
SAMPLE TEST DATA - Hospital / Doctor / Emergency SOS / Bookings
================================================================================
Base URL assumed: http://localhost:8080
Auth: this service trusts X-User-Id / X-User-Role headers forwarded by the
gateway (it does not validate JWTs itself). For local testing, set them
manually as shown below. Role must be one of: PATIENT, HOSPITAL.

All hospitals below are placed near Chennai (lon ~80.27, lat ~13.08) so the
"nearby" / "emergency-sos" geo queries return results within a 10km radius.

--------------------------------------------------------------------------------
8. DOCTOR APPOINTMENT BOOKING - patient books a regular appointment
--------------------------------------------------------------------------------
POST /api/hospital/doctor-appointments
Content-Type: application/json
X-User-Id: patient-002
X-User-Role: PATIENT

{
  "hospitalId": "HOSPITAL_1_ID",
  "doctorId": "DOCTOR_1_ID",
  "appointmentDateTime": "2026-09-25T10:30:00Z",
  "reason": "Routine cardiac checkup",
  "patientName": "Meena Pillai",
  "patientPhone": "9123456780"
}

Note: appointmentDateTime must be in the future relative to when you run
this (it's validated with @Future) - adjust the date before sending.

Reschedule (requires HOSPITAL role; X-User-Id must equal HOSPITAL_1_ID):
PATCH /api/hospital/doctor-appointments/{BOOKING_ID}/reschedule
Content-Type: application/json
X-User-Id: HOSPITAL_1_ID
X-User-Role: HOSPITAL

{ "appointmentDateTime": "2026-09-26T11:00:00Z" }

List a hospital's own appointment bookings:
GET /api/hospital/doctor-appointments
X-User-Id: HOSPITAL_1_ID
X-User-Role: HOSPITAL
